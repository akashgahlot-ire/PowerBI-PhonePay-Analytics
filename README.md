# 📖 Project Overview

This project presents an interactive **Power BI dashboard** designed to analyze PhonePe transaction data through a business intelligence lens.

The dashboard enables users to explore transaction volume, transaction value, user behavior, payment status, age segments, service categories, and weekday versus weekend usage through dynamic visualizations and interactive filters.

Rather than simply displaying transaction data, the dashboard helps identify **customer behavior, transaction trends, service performance, and key business opportunities**.

---

# 🎯 Business Objectives

✔ Monitor overall transaction volume and transaction value

✔ Analyze transaction trends over time

✔ Understand payment success and failure rates

✔ Identify high-value customer segments

✔ Compare transaction value across services

✔ Analyze user behavior by age segment

✔ Compare weekday and weekend transaction usage

✔ Deliver an interactive business intelligence report

# 📂 Dashboard Features

### 📌 Executive KPI Cards

Monitor key business metrics including:

- Total Transactions — **300K**
- Total Transaction Value — **₹3.47 Billion**
- Unique Users — **108K**
- Successful Rate — **96.00%**

The dashboard also displays month-over-month performance indicators for transaction volume and transaction value.

---

### 📈 Transactions Over Time

Analyze monthly transaction activity and transaction value trends.

The time-series analysis helps identify:

- Monthly transaction patterns
- Transaction volume fluctuations
- Transaction value trends
- High and low activity periods
- Changes in customer payment behavior

**Business Value**

- Performance monitoring
- Trend identification
- Monthly business planning
- Transaction forecasting

---

### 👥 Age Segment Contribution

Analyze transaction activity across different customer age groups.

The dashboard segments users into:

- Gen X
- Millennials
- Gen Z
- Boomers

This helps understand which customer segments contribute most to transaction activity.

---

### 💳 Payment Status Analysis

Monitor transactions based on payment status:

- Failed
- Pending
- Successful

The interactive payment-status selector allows users to focus on specific transaction outcomes.

**Business Value**

- Monitor payment performance
- Identify transaction failures
- Improve payment reliability
- Understand customer transaction behavior

---

### 🏦 Service Transaction Value Analysis

Compare transaction value across different PhonePe services.

The dashboard analyzes services such as:

- Loans
- Insurance
- Money Transfer

The analysis helps identify which services generate the highest transaction value.

### 🏆 Top 5 Users

Identify the **Top 5 Users by Transaction Value**.

This analysis helps highlight high-value customers and understand their contribution to overall transaction value.

**Business Value**

- High-value customer identification

- Revenue contribution analysis

### 📅 Weekday vs. Weekend Usage

Compare transaction activity between:

**Business Value**

- Campaign planning
- Service optimization
- Peak usage identification

Users can dynamically filter the dashboard by:

These filters allow users to perform focused analysis and explore different transaction scenarios.

# 💡 Key Insights

📍 The dashboard records approximately **300K total transactions**.

📍 Total transaction value is approximately **₹3.47 Billion**.

📍 The overall successful transaction rate is approximately **96%**.

📍 **Gen X** users contribute the highest transaction volume among the displayed age segments.

📍 **Loans** generate the highest transaction value among the analyzed services, contributing approximately **₹2.5 Billion**.

📍 Weekday usage is higher than weekend usage, with approximately **71.6%** of usage occurring on weekdays.

📍 The Top 5 users demonstrate significant individual transaction-value contributions.

📍 Transaction activity fluctuates throughout the year, highlighting changes in monthly payment behavior.
